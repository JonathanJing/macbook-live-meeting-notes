# Model attribution

This repository downloads no model weights into Git.

## Default ASR model

- Model: `mlx-community/nemotron-3.5-asr-streaming-0.6b-8bit`
- Upstream: `nvidia/nemotron-3.5-asr-streaming-0.6b`
- MLX conversion: MLX Community contributors via `mlx-audio`
- Terms: NVIDIA Open Model License, as stated by the model repository

Users are responsible for reviewing and complying with the current upstream
model terms before redistribution or commercial deployment.

## Optional note model

The note backend is configurable. Model-specific terms apply to any checkpoint
selected by the user. No optional note-model weights are redistributed here.
